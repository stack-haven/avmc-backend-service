## 2. 单 Processor 测试（§67）

### 测试入口

```go
state := NewState(...)
processor.Process(ctx, state)
```

### 测试**不得**强制启动完整 Engine

### 必须覆盖的场景

| 场景 | 目的 |
|---|---|
| 典型输入 | 验证正确性 |
| 未命中 | 验证零行为 |
| 保护区 | 被 Lock 的区间不应被修改 |
| 边界：空文本 | 不 panic |
| 边界：空 Lexicon | 不 panic |
| 边界：单字符 | 正确处理 |
| 错误：ctx 取消 | 立即退出 |
| 错误：配置非法 | New 返回 error |

### 测试结构示例

```go
func TestFuzzyProcessor(t *testing.T) {
    tests := []struct {
        name   string
        input  string
        lex    []lexicon.Entry
        config FuzzyConfig
        want   string
        locked []Span
    }{
        {"典型命中", "周莉群", ...},
        {"未命中",   "完全无关", ...},
        {"保护区",   "周莉群明天", ..., []Span{{0, 3}}},  // Lock 后不应修改
        {"空文本",   "", ...},
        {"空 Lexicon", "周莉群", nil, ...},
    }
    for _, tt := range tests {
        t.Run(tt.name, func(t *testing.T) {
            state := lexnorm.NewState(tt.input, lexnorm.WithLexicon(buildLex(tt.lex)))
            for _, sp := range tt.locked {
                state.Lock(sp)
            }
            p := fuzzy.New(tt.config)
            if err := p.Process(context.Background(), state); err != nil {
                t.Fatal(err)
            }
            if got := state.Text(); got != tt.want {
                t.Errorf("got %q, want %q", got, tt.want)
            }
        })
    }
}
```

## 3. Pipeline 测试（§68）

### 必须验证

| 项 | 含义 |
|---|---|
| Processor Order | 实际执行顺序与声明一致 |
| Error Policy | ContinueOnError / FailFast 行为符合预期 |
| Protection | Lock 的区间不被下游 Processor 修改 |
| Changes | Change 列表的 Span / From / To 正确 |
| Result | Text / Status / Duration / Steps 正确 |

### 关键不变量

- `Pipeline.Processors()` 顺序 = 实际执行顺序
- 同一 Pipeline 多次 Process 不共享 State
- ContinueOnError 模式下，单步错误不阻断后续步骤

## 4. Engine 测试（§69）

### 必须覆盖

| 项 | 验证内容 |
|---|---|
| Concurrent Normalize | 100+ goroutine 并发，零 race |
| Profile 路由 | 不同 ProfileName 走不同 Pipeline / Lexicon |
| Lexicon Snapshot | 热更新期间正在进行的请求结果稳定 |
| Middleware | panic recover / timing / tracing 正常触发 |
| Hook | PipelineStart / ProcessorStart / ProcessorEnd / PipelineEnd 全部触发 |
| Cancellation | ctx 取消时立即退出，返回 Canceled 状态 |

### 并发模板

```go
func TestEngineConcurrentNormalize(t *testing.T) {
    eng, _ := lexnorm.New(lexnorm.WithPipeline(pipeline))
    var wg sync.WaitGroup
    for i := 0; i < 100; i++ {
        wg.Add(1)
        go func() {
            defer wg.Done()
            for j := 0; j < 1000; j++ {
                _, err := eng.Normalize(context.Background(), sampleText)
                if err != nil {
                    t.Errorf("unexpected error: %v", err)
                    return
                }
            }
        }()
    }
    wg.Wait()
}
```

## 5. Race Test（§70）

### 必须执行

```bash
go test -race ./...
```

### 重点覆盖

```text
100+ concurrent Normalize
```

### 不变量

| 对象 | 是否可共享 |
|---|:--:|
| Engine | ✅ |
| Pipeline | ✅ |
| Processor | ✅ |
| Lexicon | ✅ |
| State | ❌ |
| Result | ✅ |

> 若 State 被跨 goroutine 共享，race 检测器会报警，必须修复。

## 6. Fuzz Test（§71）

### 必须覆盖场景

```text
UTF-8 边界
空文本
超长文本
组合字符
Emoji
非法 UTF-8
空 Lexicon
重复规则
冲突规则
Protected Span
```

### 核心 Fuzz

```go
func FuzzNormalize(f *testing.F) {
    f.Add("呃，佘丽群明天开会")
    f.Add("")
    f.Add("AAAAAAAAAA")
    f.Add("😀😁😂🤣😃😄😅😆😉😊😋😎😍😘🥰😗😙😚🙂🤗🤩🤔🤨😐😑😶🙄😏😣😥😮🤐😯😪😫😴😌😛")

    f.Fuzz(func(t *testing.T, input string) {
        // 不 panic，不死循环，结果可解释
        eng, _ := lexnorm.New(lexnorm.WithPipeline(smallPipeline))
        res, err := eng.Normalize(context.Background(), input)
        if err != nil {
            // Normalize 不应返回 error（除 ErrTextTooLarge）
            if !errors.Is(err, lexnorm.ErrTextTooLarge) {
                t.Fatalf("unexpected error: %v", err)
            }
            return
        }
        // Result 应满足不变量
        if !utf8.ValidString(res.Text) {
            t.Errorf("invalid UTF-8 in result: %q", res.Text)
        }
        // Original 必须不变
        if res.Original != input {
            t.Errorf("Original mutated")
        }
    })
}
```

## 7. Golden Test（§72）

### 建立

```text
testdata/*.golden
```

### 覆盖

```text
单 Processor
Standard Pipeline
Custom Pipeline
Protection
Decision
Provenance
Error
```

### 工具

推荐使用 `github.com/icholy/golden` 或自实现：

```go
func TestPipelineGolden(t *testing.T) {
    got := runPipeline(input)
    golden.Assert(t, got, "testdata/standard-pipeline.golden")
}
```

### 注意

- Golden 文件必须**可复现**（确定性 §2.4）
- Pipeline 配置变更需更新 Golden 并附 PR 说明
